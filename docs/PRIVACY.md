# xbot iOS 隐私说明

更新日期：2026-10-21。

xbot iOS 是连接**用户自行托管的 xbot 服务器**的通用客户端。开源维护渠道为 [ai-pivot/xbot-ios](https://github.com/ai-pivot/xbot-ios)，应用问题可通过 [GitHub Issues](https://github.com/ai-pivot/xbot-ios/issues) 联系维护者。维护者不提供统一 xbot 账号、默认 AI 套餐或消息托管服务，不接收你的登录凭据、消息和附件。

## 数据发送给谁

- 登录时，用户名、密码发送到你手动指定的 xbot 服务器。公网连接必须使用 HTTPS；本机及明确的局域网地址允许 HTTP，HTTP 没有传输加密，仅应在可信网络使用。
- 发送消息、回答 Agent 问题、上传所选文件或照片时，数据发送到该服务器。服务器可能把内容、历史上下文和附件发送到你配置的模型供应商、代理或工具服务。客户端维护者不指定这些接收方。
- 首次发送前，客户端展示服务器地址和能读取到的模型订阅名称、服务地址，请你核对真实接收方并明确同意。可补充实际使用的 AI、代理或工具服务商，也可确认仅使用本地模型。兼容协议名称不代表供应商身份，代理后续的接收方需由你或服务器管理员核实。
- 接收方配置变化时，原同意失效，需要重新确认。你可在“设置 → 隐私与数据”撤回同意；撤回后停止新的消息、回答和附件传输，并关闭会话通知。已发送数据无法通过撤回来追回。
- 同源图片使用 xbot 登录会话请求；外部图片请求不携带 xbot Cookie 或 Authorization。外部对象存储仍会看到正常网络请求及所请求的资源地址。

## 本机保存与权限

- 需要记住的密码、会话 Cookie、推送绑定密钥、设备推送标识和隐私同意记录保存在本机钥匙串。关闭“记住登录信息”不会保存密码，登录会话仍可用于恢复；退出登录会清除相应密码和会话。
- 外观、服务器地址、用户名、当前会话标识和通知去重状态用于恢复应用体验。聊天历史主要从你的服务器读取，不提供独立离线历史库。
- 文件与照片通过系统选择器选择，客户端不扫描整个照片库或文件系统。不请求相机、麦克风、通讯录、位置或广告标识权限。
- 应用没有广告、跨应用跟踪或第三方统计 SDK。应用开发者及其集成 SDK 不收集用户数据；用户自行指定的服务器与服务商的数据处理另受其配置和政策约束。

## 通知

通知是可选功能。拒绝通知不影响聊天。长期推送仅在用户配置自己的 APNs 桥接时启用：桥接处理设备推送标识、服务器和会话标识，并使用独立服务端凭据观察会话。客户端不会把 xbot 密码或 Cookie 发送给推送桥接。APNs 提醒只含通用提示文字，不含回答、问题正文或会话标题。设备系统设置决定通知是否显示及是否镜像到 Apple Watch。

桥接仍会接触服务器事件，应部署在你信任的环境。关闭通知或退出登录会尝试解除绑定；网络失败时，应在自己的桥接服务移除旧设备记录。

## 举报、屏蔽和删除

- 本机内容过滤仅是补充防护，不能保证识别所有有害内容。实际模型、工具及内容审核策略由服务器管理员负责。你可以屏蔽会话，并在隐私设置解除屏蔽。
- 举报默认只提交会话标识、轮次、原因和你填写的补充说明；只有你单独选择时才附带该回答正文。举报发往你自己的服务器，不会自动发送到维护者或公开 GitHub。
- 对支持移动端删除接口的服务器，可在 App 内重新验证密码并申请删除账号及关联数据。客户端仅在收到有效回执后显示“申请已受理”；只有服务器确认完成后才显示“完成删除”。回执包含处理期限。
- 旧版自托管服务器没有删除或举报接口时，客户端会明确提示未受理。你可以导出举报交给自己的管理员，或在服务器端执行账号、聊天、附件及关联工具数据的删除；可选的配套服务源码见仓库 `compliance-service/`。
- “清除此设备的账号数据”清除本机当前服务器账号的密码、会话、同意、屏蔽及恢复记录，并关闭通知；**不会删除服务器数据**。设置中保留服务器地址和通用外观偏好。
- 服务器、代理和模型供应商的数据保留期限、备份及法律保留事项由你和相应运营方决定，客户端维护者无法替所有自托管部署承诺统一期限。

## 联系与变更

应用问题请通过上述维护渠道反馈；**不要在公开问题中发布密码、令牌、聊天、附件或其他私人信息**。服务器数据访问、保留、举报和删除问题，请直接联系你自己的服务器管理员。若未来应用新增由开发者运营的数据收集或服务，本说明、隐私清单及 App Store 隐私申报必须相应更新，并在需要时重新取得同意。
