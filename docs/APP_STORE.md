# App Store 提审准备

本项目是连接用户自托管 xbot 的客户端，不提供统一账号系统、AI 套餐、托管消息或购买入口。不要套用“所有账号与模型均由开发者运营”的服务型 App 假设，也不能宣称自托管形态自动豁免所有审核要求。

## 已落实的客户端措施

- `PrivacyInfo.xcprivacy` 随实际 App 打包，使用 `CA92.1` 声明本应用容器内 UserDefaults。无跟踪 SDK、无广告标识访问。数据收集声明按当前维护者及集成 SDK 不收集用户数据的架构填写；自托管服务并非开发者固定合作方。
- 登录页及设置内可读隐私说明，公开政策 URL 为 `https://github.com/ai-pivot/xbot-ios/blob/main/docs/PRIVACY.md`；公开支持 URL 为仓库 Issues，明确禁止在那里发布私人聊天或凭据。
- 新版本不直接恢复尚未确认隐私说明的旧登录。登录凭据只发往用户指定服务器。
- AI 消息、回答和附件上传在网络请求发出前检查同意；按服务器与账号隔离，保存到钥匙串。读取订阅中的实际地址而非猜测模型厂商；代理后续接收方由用户核实。配置的完整路由（只保存摘要）或工具列表变化时使同意失效；可以撤回。明确同意不自动发送原草稿。
- 移除全局 ATS 关闭，公网强制 HTTPS，保留明确局域网 HTTP。外部图片使用无 Cookie 的临时会话，拒绝不安全重定向。保留本机服务器、局域网及反向代理子路径连接。
- 通知可选，正文与会话标题不进入本地或 APNs 提醒；仅传通用文案与必要路由标识。有限后台任务会按系统到期结束，不使用假音频、位置或 VoIP 保活。
- 可屏蔽及恢复会话，内置高风险文本的基础过滤，提供私有举报及自托管管理员导出入口。基础规则不是完整模型／图像／工具审核系统。
- 可向支持接口的自托管服务器发起完整账号与数据删除申请，显示有效回执、待处理／完成状态及期限；清除本机数据有独立入口且明确不删除远端。配套服务的人工完成记录不能代替实际数据删除。
- 保留原有首个管理员注册、聊天／SSE、工具展示、附件、AskUser、模型及各项设置、Mermaid、更新和通知功能。

## 需要在实际分发时落实的事项

1. **审核访问**：为审核员提供可访问、已配置模型的测试服务器和专用审核账号，说明如何进入完整功能。不要在公开仓库提交这些凭据。离线预览不能替代完整审核访问。需要真机与正式签名构建验证；目前没有真实 APNs 身份和设备到达证明。
2. **商店隐私元数据**：在 App Store Connect 填写政策和支持 URL，并按最终发行主体及实际集成的 SDK／服务复核隐私申报。当前架构没有维护者收集聊天、附件、密码或统计数据；如果未来新增托管服务、遥测或固定 AI 后台，必须更新清单、政策、标签和同意流程，不能沿用“未收集”。
3. **自托管删除**：通用客户端不持有用户服务器账号，无法替任意版本 xbot 安全执行远端数据库清除。若分发形态被审核要求支持注册账号的 App 内删除，可接入本仓库配套服务／原生服务器接口，并建立实际数据归属、备份、凭据失效及人工履约流程。不能只部署空队列、无限期等待或把 `web_users` 一行删除当成全部删除。
4. **自托管内容责任**：客户端未运行 Web 插件或提供插件市场，只展示服务器响应、工具结果和离线图表。应在审核备注演示服务器执行与 iPhone 原生权限的边界。如果实际分发被认定适用 1.2／4.7，需按该形态落实服务端过滤、举报处理、适用的滥用用户屏蔽、软件索引／链接和年龄限制；纯本机关键词过滤或一个 `content_filtering: true` 声明不能证明完成这些要求。不要声称对任意用户自定义模型／工具的输出作出保证。
5. **收费与登录**：当前无数字购买、付费解锁、外部充值引导或第三方社交登录。服务器“模型订阅”是配置名称，不是 App 内销售。后续增加消费型 AI 套餐或社交登录时，需重新评估地区内购政策和等效登录要求。
6. **描述与年龄分级**：如实填写生成式 AI、用户内容、连接自托管服务器、需要账号和可选通知等情况，按实际可达内容填写分级。不得把尚未配置的实时推送、独立 watchOS App 或未验证的服务器安全能力作为已交付卖点。

## 验证命令

```bash
swift test --scratch-path /tmp/xbot-ios-core-build
node --test push-relay/relay.test.mjs compliance-service/service.test.mjs
python3 scripts/check_app_privacy.py --app /path/to/built/Xbot.app
# 启动 fixture 后运行 XbotUITests，覆盖同意／拒绝／撤回、真实请求计数、回执和原有功能。
```

当前改动未发布 TestFlight／App Store、未部署用户服务器、未操作真实账号删除，也不构成苹果的审核通过承诺。

## 官方依据

- [App Review Guidelines](https://developer.apple.com/app-store/review/guidelines/)：2.1、2.5、3.1、4.5.4、4.7、4.8、5.1。
- [Required reason APIs](https://developer.apple.com/documentation/bundleresources/describing-use-of-required-reason-api)：清单与使用理由。
- [App Privacy Details](https://developer.apple.com/app-store/app-privacy-details/)：按开发者及实际第三方合作方的数据访问填写收集声明。
- [Account deletion](https://developer.apple.com/help/app-review/guideline-reference/5-1-1-account-deletion)：删除完整记录和相关数据、明确处理时间。
